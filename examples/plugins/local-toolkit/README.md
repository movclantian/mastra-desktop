# 本地多组件插件手工验收包

在“插件 → 导入插件 → 选择本地目录”中选择本目录。
安装后应显示两个独立 Skill，以及 `repository-docs` MCP。

- 创建或选择自定义 Agent，在其详情中分别勾选两个 Skill 并保存；提供一段笔记，让它总结或审阅，同时读取技能附带的参考文件。
- 在 MCP 配置里手动测试公开文档连接；使用该服务需要联网。公开服务的可用性由服务方决定。
- 停用其中一个组件或整个插件，确认后续调用不再获得该能力；重新启用后恢复。
- 修改本目录的版本和说明，检查更新、查看影响、更新，再回滚；已安装版本目录应保持独立。
- 创建可编辑本地副本后修改副本，按新的本地来源安装，确认两个安装项互不覆盖。
- 卸载时分别选择保留或移除配置与运行数据，确认手工配置的 MCP 不受影响。

此目录只提供导入材料。不会自动启动应用、MCP 或测试。
