# 工作区工具自检

先从当前会话的工具定义确认可用工具和参数，不沿用旧会话的工具数量或名称。技能本身不提供浏览器、截图或额外工具。

在用户指定工作区创建独立测试子目录，只对本轮创建的测试文件执行修改和清理，不触碰用户文件。优先只读探针；涉及真实服务、订阅、删除和审批的工具单独测试，不把测试授权扩展为发布、充值或审批业务计划。

每批最多测试5项，每项失败仅用一个最小对照例确认一次，随后记录并停止该项。命令使用执行工具支持的超时与取消参数；没有超时能力时不要启动可能永久等待的命令。界面崩溃、上下文不足或取消失效时停止本批，不另起Agent重复全量测试。

对文件搜索，用同一目录、相同内容的不同扩展名建立对照，分别测试目录搜索和明确文件路径；零结果不等于内容不存在。对写入使用读回校验；对后台命令记录实际进程标识，结束时仅取消本批启动的进程。

保留工具输入（去掉密钥）、原始结果、预期、通过/失败/未测试。空资料库返回空数组不是故障。子代理结论要核对原始输出；未经用户实际确认事件不能把 submit_plan 的文本当作批准。

最后核对测试进程和测试订阅已收尾，列出无法清理的精确标识，不声称没有执行过的项目已通过。
