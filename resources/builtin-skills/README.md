# Built-in skills

This directory contains original Mastra Desktop skills under Apache-2.0:

- `workspace-tool-check`: bounded tool checks and evidence collection.
- `windows-terminal`: Windows shell and encoding diagnostics.

Install them from the built-in Skills catalog. They provide instructions using
already available tools, not new browser or screenshot tools. They are not
feature-equivalent replacements for the removed Enterprise skill collection.

Skills from the marketplace and user-managed skills remain available through
the Skills hub; no content is copied from `@mastra/editor/ee`.
