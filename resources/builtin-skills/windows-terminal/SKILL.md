# Windows 终端

先确认工具实际使用 cmd、Windows PowerShell 还是 PowerShell 7，再选择语法。cmd 用 `&&` 条件串联，`;` 不会分隔命令；PowerShell 5.1 不支持 `&&`，必要时分开执行并检查退出码。

路径加引号；PowerShell 文件操作使用 `-LiteralPath`。避免把一种 shell 的变量、转义或删除命令拼进另一种 shell。删除只针对已核实且用户授权的具体目标，不对工作区根或用户目录执行递归清理。

乱码先区分进程原始字节编码与展示解码。用短小中文输出对照，保留退出码和输出；不要仅凭乱码外观认定 CP936 或 UTF-8，也不要修改全局代码页来掩盖单个工具解码问题。

长任务先明确退出条件与取消方式，记录工具返回的进程标识。不要按所有 node/electron 进程批量终止。工具未暴露截图能力时明确说明；如使用现有截图脚本，先读实现和保存位置，再在当前授权内调用，不声称技能自带截图能力。
