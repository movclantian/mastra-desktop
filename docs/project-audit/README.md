# 项目审查文档

本目录记录 Mastra Desktop 的代码品味、设计原则与工程问题审查结果。

文档在完成并交叉核对后，以项目源码和现有 `docs/` 示例为证据，避免把个人偏好写成项目事实。

本轮审查快照基于 `main` 与 `origin/main` 同步时的提交 `9031264`；后续代码、依赖或文档变化后，应按 `04-review-method.md` 更新受影响结论。

- [01-code-and-document-taste.md](01-code-and-document-taste.md)：代码与文档的表达品味、判断标准和可复用写作约定。
- [02-design-principles-and-influences.md](02-design-principles-and-influences.md)：从源码与 `docs/` 示例归纳的设计原则，以及可追溯的借鉴来源。
- [03-common-issues-severity.md](03-common-issues-severity.md)：通用问题清单，按等级、严重度、证据和建议分层。
- [04-review-method.md](04-review-method.md)：审查方法、证据边界和后续维护方式。
